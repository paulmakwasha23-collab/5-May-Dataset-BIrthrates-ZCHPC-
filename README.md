# Harare Birth Registry Analysis — May 2026 🇿🇼

## 📌 Project Overview
This project is an end-to-end data analysis of 3,000 birth registry records in Harare, Zimbabwe. The goal was to identify gaps in civil registration and uncover the primary barriers preventing parents from registering their children.

**Final Deliverable:** Interactive HTML Report generated via Jupyter Notebook.

## 🛠️ Tech Stack
* **Python** (Data Cleaning & Aggregation)
* **Pandas** (Data Manipulation & Grouping)
* **Plotly** (Interactive Data Visualization)
* **Jupyter Notebook** (Analysis Environment)

## 📊 Key Insights Discovered
1. **The Registration Gap:** The overall registration rate across the dataset sits at only **58.2%**, meaning over 40% of children are unregistered.
2. **The Geographic Barrier:** Registration rates drop significantly when the distance to the nearest registry office exceeds 12km. Wards like Mbare (54.8%) and Highfield (55.5%) were the lowest performers.
3. **The Socio-Economic Anomaly:** A parent's education level (Primary vs. Tertiary) showed almost no statistical difference in registration likelihood (a flat ~58-59% across the board). Even traditionally well-resourced areas like Mount Pleasant showed surprisingly low registration rates, reinforcing that **distance is a stronger barrier than income or education**.
